whereverwhenever

Moves your iPhone's location from this page. Teleport to a pin, or give it stops and it drives there on real roads: accelerating, braking into corners, waiting at lights, lingering where you'd linger, with the few metres of GPS wobble a real phone has. Find My, Maps, every app sees the same thing.

Bridge isn't running

The site can't reach your phone by itself. One local process does that. Phone plugged in and unlocked (first time; after that Wi-Fi works), then in a terminal:

pip install git+https://github.com/angadsingharora/whereverwhenever
whereverwhenever

This page reconnects on its own once it's up.

  1. iPhone: Settings → Privacy & Security → Developer Mode → on, reboot.
  2. Windows: install the Apple Devices app from the Store for the USB driver.
  3. First run: pymobiledevice3 mounter auto-mount
Want to type the trip in words? Put an Anthropic API key in ~/.whereverwhenever/key and restart the bridge.
